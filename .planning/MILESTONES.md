# Milestones

## 🚧 v0.1 — Foundation to Launch (in progress)

The single active milestone. All 55 phases (00–54) belong to it.

Project Dominion starts at v0.1.0 and evolves through v0.MINOR.PATCH. v1.0.0 is
reserved for a mature product in production with a real player base — it is not
the first release.

| Phase range | Milestone group | Delivers |
|-------------|-----------------|----------|
| 00–02 | Foundation | A repository that builds, tests and documents itself |
| 03–12 | Playable Prototype | One player grows a city in a real world |
| 13–18 | Internal Alpha | Heroes, armies, movement and deterministic combat |
| 19–27 | Multiplayer Alpha | Conquest, alliances, diplomacy and trade |
| 28–35 | Closed Alpha | Retention systems and full operator tooling |
| 36–47 | Beta | Hardened, measured, balanced and accessible |
| 48–49 | Alpha/Beta Release | Real players on real servers |
| 50–52 | Release Candidate | Reproducible production and a tested recovery path |
| 53 | Launch | Publicly available |
| 54 | LiveOps | Running as a live service |

**Started:** 2026-08-24
