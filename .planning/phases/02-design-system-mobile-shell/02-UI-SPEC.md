## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 12px | Default element spacing |
| lg | 16px | Section padding |
| xl | 24px | Layout gaps |
| 2xl | 32px | Major section breaks |
| 3xl | 48px | Page-level spacing |

Exceptions: Touch targets are strictly 44px minimum (`MIN_TOUCH_TARGET = 44`).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | bg.base (Light: #F4EEE2, Dark: #0E1116) | Background, surfaces |
| Secondary (30%) | surface.raised (Light: #FFFFFF, Dark: #161B22) | Cards, sidebar, nav |
| Accent (10%) | accent.bronze / gold / steel | Primary actions, active tab indicator, progress fills |
| Destructive | danger (Light: #A4212B, Dark: #C4323D) | Destructive actions only |

Accent reserved for: Primary interactive elements (buttons, active tabs), progress bar fills, and selected state outlines. Never for text unless specifically a link/action.
